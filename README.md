# myDeck

Um projeto desenvolvido em **Go** para estudar e praticar os fundamentos da linguagem por meio da implementação de um baralho de cartas.

## Sobre

O projeto consiste na criação e manipulação de um baralho, permitindo realizar operações como criação, distribuição, embaralhamento e persistência das cartas em arquivos.

A implementação foi utilizada como forma de explorar recursos da linguagem e da biblioteca padrão do Go, buscando entender como esses conceitos são aplicados na prática.

## Conceitos explorados

- Structs e métodos
- Interfaces
- Slices
- Ponteiros
- Tratamento de erros
- Packages e módulos
- Leitura e escrita de arquivos
- io.Reader e io.Writer
- Testes automatizados
- Manipulação e organização de dados

## Funcionalidades

- Criação de um baralho com 52 cartas
- Distribuição de cartas
- Embaralhamento do baralho
- Salvamento do baralho em arquivo
- Carregamento do baralho a partir de arquivo

## Tecnologias

- Go
- Go Standard Library
- Git

## Executando o projeto

Clone o repositório:

    `git clone https://github.com/lucasvsclls/myDeck.git`

Acesse o projeto:

    `cd myDeck`

Execute o projeto:

    `go run .`

Para executar os testes:

    `go test ./...`

## Objetivo

O objetivo do projeto é consolidar os fundamentos de Go através de uma implementação prática, explorando conceitos importantes da linguagem e desenvolvendo familiaridade com sua biblioteca padrão.

O projeto faz parte dos meus estudos de desenvolvimento backend com Go.
